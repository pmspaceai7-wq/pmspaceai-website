Both 404 errors are caused by SLUG MISMATCHES in /src/lib/resources.ts

When a tool is defined with a certain slug, that slug becomes the URL:
  - Defined slug "crm" → URL is /tools/crm
  - But Google indexed /tools/custom-crm
  - Result: 404 when Google tries to access it

This is a configuration mismatch, not a broken code issue.
