# Glossary Expansion Plan

The glossary should become a stronger entity layer for AI visibility. Each term should connect a definition, a product workflow, and a canonical page.

## Priority Term Groups

- Construction AI: construction AI, predictive analytics, machine learning, generative AI, agentic AI, AI assistant, AI recommendation engine
- Project controls: schedule risk, delay prediction, cost forecasting, budget overrun, earned value, project controls
- Document workflows: RFI, submittal, document control, closeout, punch list, approval workflow
- Systems and integrations: BIM, Revit, Autodesk, Microsoft 365, QuickBooks, Sage, common data environment
- Buyer evaluation: construction management software, Procore alternative, software comparison, implementation, migration

## Required Fields For Each Term

- Term
- Plain-English definition
- Why it matters in construction
- Related Space AI workflow
- Canonical page to cite
- Related glossary terms

## Internal Linking Rule

Every glossary term should link to:

- One docs page
- One product or workflow page
- One related glossary or resource page
